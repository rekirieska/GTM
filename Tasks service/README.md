### Локальные точки отказа

| Точка отказа | Поведение модуля |
| :--- | :--- |
| Принимающий сервис (Notification Service) недоступен или возвращает ошибку | Модуль не падает. Неудача логируется в терминал, клиенту возвращается код 201 и созданная задача. |

---

### Запуск

```bash
pip install -r requirements.txt
uvicorn tasks_service:app --reload --port 8000
```

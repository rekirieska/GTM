# GTM
Good Task manager

[Техническое задание](https://docs.google.com/document/d/1ivg931RRbbFaZHiUYeuvgUXxbjUk89q9/edit?usp=sharing&ouid=115162351960228649031&rtpof=true&sd=true)

Функционал:
1. Создание базовой программы
1.1 GUI представляет из себя окно на котором сетка задач.
1.2 Присутствуют три кнопки (создание задачи, удаление задачи, выбор корневой папки)
1.3 Задачи представляют из себя простой .md файл в папке.
2. Создание дополнительного функционала в виде панели слева с древом корневой папки, где можно просматривать файлы в подпапках.
3. Улучшение интерфейса
